# GramGenie Pfam models

Six original, unmodified Pfam HMMER3 profiles downloaded from EMBL-EBI InterPro.
The exact versions, gathering cutoffs, source URLs, retrieval dates, and SHA-256
checksums are in `models.tsv`. Use both sequence and domain GA cutoffs.

Run `python MagicLamp.py GramGenie --help`; see
[`docs/GramGenie.md`](../../docs/GramGenie.md) for input formats, outputs,
interpretation limits, and deliberate model updates.
